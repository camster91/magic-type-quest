# BloomType teacher quick start (5 minutes)

1. **Open the teacher page** on the classroom computer: `https://bloomtype.ashbi.ca/magic-type-quest/teacher.html`
2. **Make your class:** type a class name and tap *Create class*. You get a 6-character code.
3. **Print student cards:** tap *Print student cards* and cut them out.
4. **Students join:** each student opens BloomType → *Profile*, types their first name and the class code, and taps *Save*.
5. **Set work (optional):**
   - *Assignment:* "Finish Level 3 by Friday".
   - *Spelling words:* paste this week's list. Students get a *Practice class words* button.
6. **Check progress:** open the teacher page and tap your class. You see each student's levels, speed, accuracy, weak keys, minutes this week and assignment status. Tap *Export CSV* for your gradebook.

**Good to know**
- Progress is saved on the computer the student uses. Use the same computers each time, or have students write down their **save code** from the Profile screen.
- Nothing is sent online. There are no ads and no accounts.
- 10–15 minutes a day works better than one long session a week.
