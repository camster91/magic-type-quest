# Browser application shell — #160

`src/v2/app/V2Shell.ts` owns the semantic browser frame. It creates the skip link, header, one prominent Meadow action, habitat and mastery summaries, World Map and Field Guide access, world host, live status, loading/error regions, parent/teacher exit links, and DOM dialog root. The World Map and Field Guide are route placeholders until #172/#170; the home and world surfaces are a shell, not a completed typing encounter. No v2 learner progress is written by this issue.

The shell lazy-loads Phaser and `BootScene` only after Start Meadow. The world host stays within a 16:9 responsive container. One `ResizeObserver` in the shell reports host changes to Phaser; BootScene redraws on the scale event and removes its listener on shutdown. The canvas is labeled and described by `#v2-world-summary`; objectives, resulting habitat state, and announcements live in DOM. `Phaser.AUTO` selects a graphics path with Canvas fallback where supported. The initial v2 shell chunk is about 9.5 kB uncompressed (3.9 kB gzip); Phaser remains a separate approximately 1.38 MB / 358 kB gzip chunk until the world is requested. #165 will enforce final pack budgets.

Native modal `<dialog>` handles inert background and focus containment. Settings and pause restore focus to their invoker on Escape or close. The settings dialog offers reduced motion for this session, and system reduced-motion is honored in CSS. Sound is not required. The general DOM dialog contract is `naturequest:v2:dialog-request` on `#v2-app` with `{ type: 'completion', description }` or `{ type: 'confirmation', description, onConfirm }`; future encounters can use it without constructing Canvas dialogs. A browser `naturequest:v2:recoverable-error` event accepts `{ kind: 'corruptProgress' | 'storageUnavailable' | 'unsupportedGraphics' | 'offlineAsset' }`. It shows child-safe recovery text and preserves v1 storage. #162 will connect actual storage failures. Failed dynamic imports require a fresh module map; online retry reloads the shell and resumes the Meadow request using a one-time session marker.
