# Archived v1 plans

These are historical BloomType v1 design, planning and audit documents. They are kept for context only and are **not** current plans. Their "use `ROADMAP.md`" banners refer to the repository-root [`ROADMAP.md`](../../../ROADMAP.md).

- `BLOOMTYPE-COMPLETE-PLAN.md`, `BLOOMTYPE-PLAN.md`, `IMPLEMENTATION-PLAN.md`, `PRACTICE-MODE-PLAN.md`: v1 feature plans. Most of this work has shipped.
- `SCHOOL-READINESS-AUDIT.md`: the v1 school-readiness audit. Its open gates now live in [`docs/LAUNCH-READINESS.md`](../../LAUNCH-READINESS.md).
- `design/2026-08-gameplay-hud-mockup.html`: an August 2026 HUD mockup that was labelled "v2" before the v2 product contract existed. It uses hearts and lives, "magical" wording and a horned pet, all of which [the v2 product contract](../../v2/PRODUCT-CONTRACT.md) now rules out. Do not use it as v2 direction.

The v1 imagery and wording in these files (magic, spells, wizards, unicorns, dragons) are v1 history. They are not v2 creative direction.
